# Hi there, welcome!

I'm Ben, a Senior Frontend Engineer from 🇮🇱 Israel. I build AI into how software gets made, and I build enterprise frontends that hold up at scale.

- 🔭 I'm currently at [Riverbed](https://www.riverbed.com/), the sole frontend engineer on the Agent Lifecycle Management Platform, and I maintain the shared design system used across all Aternity products.
- 🤖 I run delivery with an AI workflow I designed: Claude Code agents connected over MCP to Jira, Bitbucket and the browser, taking each ticket from plan to code to tests to PR.
- 🌱 Currently building an AI agent that migrates Angular applications to React + TypeScript.
- 💬 Feel free to reach out about frontend architecture, design systems, AI agents and MCP, or React in general.

<br>

## 🚀 Featured project
**[whatsapp-mcp](https://github.com/BenGedi/whatsapp-mcp)**: an MCP server that connects Claude to WhatsApp (Go + Python). Forked from lharries/whatsapp-mcp and extended with Claude Code: group management tools, quoted replies, security hardening and tests.
